12. Điều chưa thể biết chỉ từ cấu trúc code

  • Nội dung cụ thể của prompt runtime phụ thuộc project/source/series DB; HTML này mô tả template và field, không thay thế một capture có request id.
  • Chưa chạy prompt thật trong phiên này, nên không đo lại prompt chars/output chars mới.
  • Batch size hiện tại của prompt pack là 5; shot breakdown vẫn là một call duy nhất trong code hiện tại, chưa có batch/resume implementation.
  • Prompt được lưu DB có thể được bổ sung segment prefix nếu model output thiếu duration/continuity; vì vậy “prompt model trả” và “prompt stored” không luôn giống hệt nhau.
