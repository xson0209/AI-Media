# Nhãn triage

Các skill dùng 5 vai trò triage chuẩn. File này ánh xạ vai trò đó sang tên nhãn thật trong issue tracker của repo.

| Vai trò trong mattpocock/skills | Nhãn trong tracker | Ý nghĩa |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Cần maintainer đánh giá |
| `needs-info` | `needs-info` | Đang chờ người báo issue bổ sung thông tin |
| `ready-for-agent` | `ready-for-agent` | Đã đủ rõ để agent làm |
| `ready-for-human` | `ready-for-human` | Cần người thật xử lý |
| `wontfix` | `wontfix` | Không xử lý |

Khi skill nhắc tới một vai trò, dùng tên nhãn tương ứng trong bảng này.
